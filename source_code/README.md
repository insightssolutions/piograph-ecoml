# Source Code

## Overview

This directory contains the implementation resources supporting the PioGraph\-EcoML framework.

The framework consists of two complementary methodologies:

- Integrated Modeling Improvement Methodology (I\-MIM)
- Continuous Modeling Improvement Methodology (C\-MIM)

Together, these methodologies support transportation mode\-choice prediction using econometric, machine\-learning, deep\-learning, and graph\-based analytical approaches.

---

## I\-MIM Framework

The Integrated Modeling Improvement Methodology (I\-MIM) focuses on improving predictive performance through structured model development, feature engineering, class\-balancing techniques, feature selection, and ensemble\-learning approaches.

Key components include:

- Logistic Regression
- Random Forest
- Balanced Random Forest
- Recursive Feature Elimination (RFE)
- SMOTE\-based balancing
- Ensemble learning techniques

---

## C\-MIM Framework

The Continuous Modeling Improvement Methodology (C\-MIM) focuses on progressive deep\-learning enhancement through sequential model refinement.

Key components include:

- Deep Neural Networks (DNN)
- Convolutional Neural Networks (CNN)
- Recurrent Neural Networks (RNN)
- Long Short\-Term Memory (LSTM)
- Hybrid CNN\-LSTM architectures
