# Reproducibility Guide

This repository contains the materials required to reproduce the experiments and results presented in the PioGraph-EcoML framework.

**Requirements**

Python 3.11+

TensorFlow

Scikit-learn

Pandas

NumPy

**Workflow**

Prepare the dataset.

Execute preprocessing scripts.

Train the models.

Run evaluation scripts.

Generate figures and tables.

Perform statistical validation using McNemar tests.
