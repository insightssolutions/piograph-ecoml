# PioGraph-EcoML
A Novel Data‑Driven Graph‑Based Framework for Integrating Econometric Models and Machine Learning Algorithms

PioGraph-EcoML is a novel graph-based framework that integrates econometric models and machine learning algorithms to improve predictive performance, interpretability, and decision support.

**Objectives**
Integrate econometric and machine learning approaches
Enhance model explainability through graph-based relationships
Support transportation and mobility analytics
Enable future enterprise integration with platforms such as Odoo
