# PioGraph-EcoML
A Novel Data-Driven Graph-Based Framework for Integrating Econometric Models and Machine Learning Algorithms.

**Overview**
PioGraph-EcoML is a hybrid framework designed to integrate econometric methods, machine learning algorithms, and graph-based representations to enhance predictive performance and interpretability in transportation mode-choice analysis.

**Repository Structure**

research/ : Manuscripts and publication materials
datasets/ : Data and metadata
source_code/ : Model development and evaluation scripts
models/ : Trained model artifacts
results/ : Figures, tables, and validation outputs
docs/ : Framework and reproducibility documentation

**Reproducibility**

The repository provides the materials required to reproduce the experiments, results, and analysis presented in the associated publication.
